# Elite_dangerous_Filter v0.1.2

## English

Download **EliteDangerousFilter.exe** below and run it on 64-bit Windows. No Python installation is required; searches need internet access.

**The colonisation candidate finder is now released. The pirate massacre finder remains in testing.** Pirate results are candidates, not guaranteed live missions or confirmed RES availability; verify them in game. Construction-slot filtering is not included.

[English tool rules](../../README_search_logic.md) · [简体中文](#中文)

### Features

- Carrier parking finder keeps its name and now uses catalogued carrier counts with optional inclusive minimum/maximum counts. Station totals no longer predict parking. Incomplete station types remain Unknown; unknown counts cannot satisfy bounds. Bilingual UI, count-bound session persistence and CSV export are supported.
- Main-window system filters reuse planet/independent ring groups and verified nearest-populated distance with an editable population threshold. Ordinary system fields add station/carrier counts, all-faction/affiliation counts and non-Anarchy potential-issuer counts. Local checks follow cheap filtering; drafts, conditions, diagnostics, bilingual editing and complete CSV evidence are supported without imposing colonisation eligibility.
- Colonisation candidate finder: strictly zero population, no stations (including carriers) and no permit requirement. Two independent optional ly filters: regional reference/radius and minimum/maximum distance to the nearest system with population > 1, combined with AND when both enabled. Find the nearest qualifying system before checking inclusive bounds; blank means unrestricted, and minimum-only/maximum-only inputs are supported. Strict minimum system value is also optional.
- Editable planet and independent ring condition groups: AND requires all groups to exist; OR requires any group. Conditions within a group match the same planet/ring; a planet may satisfy multiple groups. Planet-local ring conditions and independent ring requirements are separate.
- Planet properties, materials, signals and orbital properties; moon relationships and inferred binary membership based on a shared immediate virtual barycentre and matching periods. Ambiguous relationships remain unknown.
- Bilingual UI, saved condition-group drafts, cancellation, CSV export and copy-system action. Full body records and station-absence verification, short-lived caches and bounded body-query concurrency. Candidate page limits and unknown records are reported.

### Fixes

- Exclude the anomalous Spansh `Test` system (ID64 `7780433924818`, listed 1 ly from Sol) and its stations from general searches, carrier parking candidates and midpoint results. Match only the exact system name or ID; other system names containing `Test` remain eligible.

### 功能

- 航母工具保留“航母车位查找”名称，改用已收录航母数量筛选，支持含边界的最少／最多数量；去掉按站点总数预测车位的规则。站点类型不完整时显示未知，未知数不能满足数量范围；同步双语、范围会话保存及 CSV 导出。
- 主界面星系筛选复用星球／独立星环条件组及可编辑人口门槛的最近有人距离；普通字段新增站点／航母数量、全部及按阵营的小派系数量、非无政府的潜在任务派系数量。先做低成本筛选再本地核实；支持草稿、条件读取、诊断、双语编辑及完整 CSV 证据，不附带殖民准入限制。
- 殖民候选星系查找：强制零人口、无站点（含航母）、无需许可。两套独立可选 ly 条件为区域参考／半径、距最近人口 > 1 星系的最小／最大距离，同时启用为 AND；先找最近达标星系再判断含边界的上下限，支持单边距离，留空不限。星系价值下限也可选，填写时要求严格大于阈值。
- 可添加星球及独立星环条件组：AND 为每组都存在匹配，OR 为任一组存在匹配。组内条件须由同一颗星球／同一个星环满足，允许同一天体满足多个组。星球内的星环条件与独立星环要求分别设置。
- 星球属性、材料、信号及轨道属性；卫星关系，以及共同直接虚拟质心和相同周期推定的互绕成员。复杂或缺失关系标为未知。
- 中英文界面、条件组草稿保存、停止查询、CSV 导出及复制星系名。完整天体查询、无站点复核、短期缓存与受控天体并发；报告分页限制及未知记录。

### 修复

- 排除 Spansh 中的异常 `Test` 星系（ID64 `7780433924818`，记录距离 Sol 为 1 ly）及其站点，使其不再出现在通用检索、航母停车候选和中点查找结果中。仅匹配完整星系名或 ID，不影响名称中包含 `Test` 的其他星系。
