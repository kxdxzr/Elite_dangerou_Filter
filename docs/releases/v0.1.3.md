# Elite_dangerous_Filter v0.1.3

## 中文

下载附件 **EliteDangerousFilter.exe**，Windows 64 位双击运行，无需安装 Python；查询需要联网。旧版数据目录及会话继续沿用，替换EXE前建议备份 `%LOCALAPPDATA%\EliteDangerousFilter`。

### 新增与改进

- **工程师途中采购**：独立窗口，目的地从25位舰船工程师的“工程师名 — 星系”列表选择。可添加多项采购清单，每项独立指定模组／舰载武器、规格、折扣和新鲜度；同一站必须满足全部采购项。支持自定航程、多跳行程、最多额外估算跳数、到站距离`ls`、忽略航母及忽略地面采购站；清单及草稿随会话保存。结果与CSV按项展示规格、优惠来源、两段距离和估算跳数。**不核查购买数量，不规划分多站凑单；估算跳数不是已验证航线。** [详细说明](../engineer-shopping.md)
- **已知折扣筛选**：出售舰船／模组增加“不限／是”，按已知地点和实际控制势力／状态规则复核同件商品，分列显示优惠幅度及来源。不下载标准价格表，不计个人等级／效忠奖励，不猜测叠加优惠。规则未知不命中“是”。[规则与限制](../station-discounts.md)
- **单栏规格选择**：核对全部153种内置模组／武器，保存真实等级＋级别组合；Plasma Accelerator为2C／3B／4A，Rail Gun补齐2B。修复旧缓存和学习逻辑丢失对应关系的问题，不再任意拼接等级和级别。旧条件保留原义，未收录规格仍可手填查询。
- **主窗口更清晰**：普通条件新增分类，模组按槽位类型浏览；结果和CSV按实际搜索条件动态拆列，各参考星系距离、商品规格、优惠等分别显示，不再堆入“关键信息”或导出整份原始JSON。
- **所有结果表支持表头排序**：点击升序／再点降序；数值、时间、自然名称排序，未知始终在末尾。保留选中记录和正确复制，切换语言／分批载入仍保留排序。只改变显示，不改变内部航线顺序；有序途经点编辑列表不启用排序。
- **中子星跳跃规划器现已打包发布**：保存Journal／Coriolis配船，支持有序途经点和分段规划；显示普通满油及理论中子增压跳距、配船身份，修正3级Guardian FSD Booster增程为7.75 ly。每段按满油计算，不保证途经点可补油；中途失败可在确认后导出已完成部分。[规划器说明](../route-planner.md)
- **稀有商品顺路中子辅助（实验性）**：同星系只计一个目的地，每势力最多5个。可选顺路几何筛选，按30°／10%→45°／25%→60°／50%逐势力放宽，有结果即停；仅使用来源200 ly内、到站≤100 Ls的参考中子星。40／50 ly模型只作辅助，不用于淘汰，**不保证实际省跳**。
- **CSV统一来源信息**：顶部为作者kxdxzr、项目、版本0.1.3、含时区时间及项目链接，随后空行、表头和数据；英文导出使用英文标签。航线CSV移除每行重复的内部状态列，未完成导出确认保留。

### 兼容性与限制

- 旧条件文件、规格筛选及会话继续支持；旧单项采购参数迁移为清单首项。普通主窗口的行内多选仍为OR；工程师采购清单中的多选名称要求全部有货。
- CSV读取程序需要跳过顶部5行来源信息和1个空行；结果列会随条件变化，不再提供`raw_json`／`distances_json`。
- 采购折扣、库存、工程师解锁、许可与实际航线请在游戏内核实。检索达到数量／页数限制可能不完整，排序仅覆盖已取回结果。
- 海盗任务查找仍为测试功能；殖民查找仍将含航母星系排除，建设槽位数量筛选仍未纳入。此版本不宣称修复这些限制。

### 发布验证

- 本地Windows／Python 3.13完整测试327项通过，源码编译检查通过。
- 实际Windows单文件EXE通过离线界面冒烟检查、独立进程会话写入及重启读取验证，覆盖中英切换、采购清单、成对规格和排序。
- 附件`SHA256SUMS.txt`提供EXE的SHA-256校验值。验证均使用隔离数据目录，不覆盖正常用户会话；不代表所有在线数据和游戏内情况均已验证。

## English

Download **EliteDangerousFilter.exe** and run it on 64-bit Windows; Python is not required. Queries need internet access. Existing sessions/data locations remain supported; back up `%LOCALAPPDATA%\EliteDangerousFilter` before replacing the EXE.

### Highlights

- **Engineer trip shopping:** a dedicated window with 25 ship-engineer destinations, independent shopping-list specifications/discount/freshness requirements and an ALL-items-at-one-station check. Custom jump range, automatic multi-jump estimates, maximum estimated extra jumps, arrival `ls`, carrier/planetary-station exclusions, saved lists/drafts and per-item evidence columns. Quantities and multi-station baskets are not planned; **distance-only jump estimates are not verified routes**. [Details](../engineer-shopping.md)
- **Known discounts:** Any/True filtering for ships/modules using documented station and controlling-Power/state rules, with separate reduction/source columns. No standard-price download, personal/pledge bonuses or unverified stacking; unknown rules do not qualify. [Rules](../station-discounts.md)
- **Single specification selector:** audited paired specifications for all 153 bundled module/weapon names; Plasma Accelerator offers 2C/3B/4A and Rail Gun includes 2B. Learning/cache updates preserve actual pairs instead of manufacturing a Cartesian product. Legacy filters remain valid and unlisted specifications may be entered manually.
- **Clearer main search:** condition categories, module slot browsing and separate condition-driven table/CSV columns. Per-reference distances, item specifications and discounts no longer share a packed information column or full raw-JSON export.
- **Sortable results everywhere:** click headers to toggle direction; numeric/time/natural-name sorting, unknowns last, correct selection/copy identity and sorting retained during localisation/streaming. Model/route order is unchanged; the ordered-waypoint editor is not sortable.
- **Neutron jump planner now included in the Windows asset:** Journal/Coriolis builds, saved ships, ordered waypoints, independently full-tank legs, ship identity and theoretical normal/neutron range previews. Correct class-3 Guardian FSD Booster boost: 7.75 ly. Refuelling at waypoints is not guaranteed; partial routes require export confirmation. [Planner](../route-planner.md)
- **Experimental rare-goods neutron alignment:** unique systems, max five per Power, optional geometry tiers relaxed per Power; anchors within 200 ly of the source and arrival ≤100 Ls. The fixed 40/50 ly model is advisory, not a rejection gate or proof of real jump savings.
- **CSV provenance:** five initial rows identify author kxdxzr, project, version 0.1.3, timezone-aware export time and project URL, followed by a blank row and the result header. English exports use English labels. Repeated internal route-status columns are removed; incomplete-route confirmation remains.

### Compatibility and limitations

Legacy conditions, sessions and partial/multi-value module filters remain supported; old single-item shopping sessions migrate to the first list entry. Main-window OR semantics are unchanged, while engineer-shopping names mean ALL. CSV readers must skip five provenance rows plus one blank row; columns are condition-driven and `raw_json`/`distances_json` are no longer exported. Stock, discounts, engineer access, permits and actual routes require in-game verification. Result/page limits may leave searches incomplete; ranking applies only to fetched matches. Pirate finding remains in testing. Colonisation still excludes carrier-containing systems, and construction-slot counts remain out of scope.

### Validation

327 local Windows/Python 3.13 tests and source-compilation checks passed. The actual single-file Windows EXE passed offline UI smoke checks plus independent-process session write/restart/read tests, covering bilingual windows, shopping lists, paired specifications and sorting. `SHA256SUMS.txt` contains the asset checksum. Tests use isolated data directories and do not overwrite normal user sessions; they do not establish the accuracy of every live-data or in-game scenario.
