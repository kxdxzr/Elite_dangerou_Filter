# Elite_dangerous_Filter v0.1.1

[English](#english) · [简体中文](#中文) · [Releases / 发行版本](https://github.com/kxdxzr/Elite_dangerous_Filter/releases)

## English

Download **EliteDangerousFilter.exe** from the assets and run it on 64-bit Windows. No Python installation is needed; searches require internet access.

> **The pirate massacre finder is still being tested.** Its results are candidate source/target pairs, not guaranteed live missions, issuer counts or RES availability. Ring-based inference is not confirmed RES and never implies RES Low. Verify candidates in game.

### Changes

- Repository renamed to **Elite_dangerous_Filter**, with separate [English](https://github.com/kxdxzr/Elite_dangerous_Filter#readme) and [Chinese](https://github.com/kxdxzr/Elite_dangerous_Filter/blob/main/README_zh-CN.md) README files and matching-language GUI screenshots.
- Instant bilingual UI switching, preserving raw conditions and game names, with persistent language selection.
- Pirate massacre candidates: EDTools pairs, RES Low priority, strict CNB fallback, faction presence/control, independent total/Federation/Empire minima and controlling Power filters for source, target or both.
- Separate inferred RES and Unknown labels; public JSON catalogue for unlimited radius. Fixes for EDTools HTTP 406, thousands-separated row counts and coverage validation.
- Batched controller/Power prefilters, record reuse, gzip and bounded concurrency; short-lived caches, forced refresh, throttled progress and incremental table rendering.
- Minor-faction suggestions support typing, paste/IME and mouse selection, preserving official names and punctuation.
- New source pad, source station maximum arrival Ls and target ring maximum arrival Ls filters. Pad/distance must match the same station; rings use full body records.
- Separate source/target copy buttons, station/ring result columns and CSV export; all new settings survive session restoration.
- Atomic persistence of main-condition drafts and all four tool settings, including cross-process restoration.

145 automated tests; pre-release verification includes compilation, bilingual four-window EXE loading and save/restore in two independent EXE processes.

The data directory remains `%LOCALAPPDATA%\EliteDangerousFilter\`, with old-session compatibility. Third-party records are not live stock, vacancies or mission boards. The rare-goods tool's combined Powerplay-state mapping remains unverified.

> **海盗任务查找功能仍在测试中。** 返回的是候选来源／目标，不能保证实时任务、派系任务数量或 RES 可用性。星环推定不等于已确认 RES，也不推定 RES Low；请在游戏中核实。

### 更新内容

- 仓库名称更新为 **Elite_dangerous_Filter**；README 分为 [英文主页](https://github.com/kxdxzr/Elite_dangerous_Filter#readme) 和 [中文说明](https://github.com/kxdxzr/Elite_dangerous_Filter/blob/main/README_zh-CN.md)，分别展示对应语言的 GUI 截图。
- 中英文界面即时切换，保持原始查询条件和游戏名称，并保存语言选择。
- 新增海盗任务候选工具：EDTools 配对、RES Low 优先、严格 CNB 回退、小派系存在／控制条件、独立任务／联邦／帝国最少数量与控制 Power 来源／目标／双方筛选。
- 星环推定 RES 与情况未知分别标注；无限半径使用完整公开 JSON 目录，修复 EDTools HTTP 406、千分位行数及覆盖校验。
- 控制派系／Power 批量预筛、详情复用、gzip 与受控并发；短期缓存、手动强制刷新、进度节流及分批绘表。
- 小派系名称联想支持实际打字、粘贴／输入法和鼠标选择，保留正式名称及标点。
- 新增来源停机坪、来源站最大到达 Ls、目标星环最大到达 Ls；来源停机坪与距离须由同一站满足，星环使用完整天体数据。
- 可分别复制任务来源／目标星系；新增站点／星环结果列及 CSV 导出，全部新条件随会话恢复。
- 延续主界面草稿、四个辅助工具参数的原子保存与跨进程恢复。

145 项自动化测试；发布前验证编译、真实 EXE 中英文四窗口加载及两个独立进程的会话保存／恢复。

数据目录保持 `%LOCALAPPDATA%\EliteDangerousFilter\`，兼容旧会话。查询基于第三方记录，非实时库存／空位／任务面板。稀有商品工具的 Powerplay 状态合并映射仍未验证。
